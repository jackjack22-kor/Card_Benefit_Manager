# 발급 가능 신용카드 우선 검증 배치

## 결정 사항

- 공개 배포판의 1차 공식 검증 범위는 신용카드로 한정한다.
- 삼성, 신한, 현대, KB국민, 롯데, 우리, 하나, NH농협, IBK기업은행, BC 바로카드의 10개 발급사를 대상으로 한다.
- 카드사별 약 20종, 총 200종을 우선 배치로 운영한다.
- 단종 또는 신규 발급 중단 상품은 상세 데이터가 남아 있어도 배치에서 제외한다.
- 체크카드는 기존처럼 `operational_candidate`로 보존하되 공식 상세 검증과 계산 모델 반영 대상에서는 제외한다.

## 선정 비율

발급사별 20종은 아래 순서로 채운다.

1. 카드고릴라 카드사별 인기 목록의 상위·대표 카드 5종
2. 카드사 공식 프리미엄 라인과 연회비 10만원 이상 상품을 중심으로 최대 8종
3. 공식 목록에 먼저 수집된 상품, 최근 출시 상품, 혜택·브랜드 정보가 충실한 대표 상품

인기 카드와 프리미엄 카드가 겹치면 한 상품으로 계산한다. 프리미엄 상품이 8종보다 적은 발급사는 인기·대표 상품으로 나머지를 채운다.

## 인기 순위 근거

- 1차 신호: [카드고릴라 신용카드 TOP100](https://www.card-gorilla.com/chart/top100)
- 발급사별 신호: `https://www.card-gorilla.com/team/detail/{teamId}`
- 보조 신호: 카드고릴라 월간 결산, 신규 카드 차트, 카드사 공식 추천·인기 정렬

카드고릴라 차트는 카드 상세 페이지 조회와 온라인 신청 전환을 함께 사용하므로 대중적 관심과 신청 행동을 파악하는 데 적합하다. 다만 제3자 인기 순위는 신규 발급 가능 여부의 증거로 사용하지 않는다.

## 발급 가능 판정

상태는 발급 확인 수준에 따라 분리한다.

- `pending_official_check`: 제3자 후보에서 단종 표시는 없지만 카드사 공식 신청 경로를 아직 확인하지 않음
- `officially_listed`: 카드사 공식 현재 상품 목록에는 있으나 상세 약관·신청 가능 여부 검증이 남음
- `officially_issuable`: 카드사 공식 상품 상세 또는 신청 화면에서 신규 발급 가능함을 확인함
- `official_application_reachable`: 카드사 또는 공식 카드 앱의 신청 페이지가 정상 응답함
- `official_application_url_verified`: 카드사 공식 도메인과 상품코드가 포함된 신청 URL은 확인했으나 자동 요청이 차단됨
- `official_application_not_confirmed`: 공식 신청 경로를 확인하지 못해 공개 목록에서 제외함

공식 확인 시에는 상품 상세 화면, 카드 신청 버튼 또는 신청 단계 진입, 최신 상품설명서·약관 중 두 가지 이상을 확인한다. 기존 회원용 안내 페이지만 남은 상품은 발급 가능으로 승격하지 않는다. 공식 신청 경로가 확인되지 않으면 조사 기록은 보존하되 공개 목록에서는 제외한다.

## 검증 순서

1. 공식 신규 발급 가능 여부와 카드명·상품코드를 확인한다.
2. 국내전용·VISA·Mastercard·American Express 등 브랜드별 연회비와 서비스를 확인한다.
3. 전월 실적 구간, 실적 제외 항목, 월·연간 한도, 연회비 기준 주기를 기록한다.
4. 주요 혜택별 할인·적립률, 건당 조건, 통합 한도와 제외 조건을 구조화한다.
5. 공식 이미지와 상품설명서 URL을 고정하고 확인일을 기록한다.
6. 계산 모델과 자동 감사 시나리오가 준비된 카드만 추천 계산에 연결한다.

## 교체 규칙

- 공식 확인 중 단종·신규 발급 중단이 확인되면 즉시 우선 배치에서 제외한다.
- 같은 발급사의 다음 순위 비단종 신용카드를 넣어 발급사별 20종을 유지한다.
- 과거 상세 검증을 마친 카드라도 신규 발급 중단이면 공개 신규 카드 목록에는 노출하지 않는다.
- 검증 오버레이와 과거 사용자 저장값은 삭제하지 않는다. 발급 중단은 신규 선택 가능 여부만 바꾸며 기존 사용자의 설정·실적을 초기화하지 않는다.

## 현재 상태

`npm run catalog:queue`는 전체 미검증 1천여 종 대신 이 200종만 기본 작업 목록으로 출력한다. 2026-07-10 현재 후보 190종의 발급 경로 검증을 완료했다. 공식 신청 페이지 응답 94종, 공식 신청 URL 확인·자동 응답 차단 13종, 공식 신청 경로 미확인 83종이다. 기존 KB 공식 상세 2종과 공식 목록 8종을 더해 공개 신용카드 목록에는 117종만 노출한다.

190종 모두 연회비·전월실적·요약혜택·상세혜택 확인값을 보유하고, 국내전용 1종을 제외한 189종은 제휴 브랜드 확인값을 보유한다. 이 값은 상세 후보 데이터이며 카드사 공식 상품설명서와 대조되기 전에는 계산 모델 또는 `official_detail_verified`로 승격하지 않는다. 카드사별 결과와 공개 제외 목록은 `docs/PRIORITY_CREDIT_CARD_VERIFICATION_RESULTS.md`에 기록한다.

공개 신용카드 117종의 이미지는 `image/public-catalog`에 로컬 자산으로 고정한다. `npm run catalog:cache-images`로 공개 안전 목록에 속한 신용카드만 다시 내려받으며, 외부 이미지 URL은 로컬 이미지 생성 입력으로만 사용한다.

구형 `American Express The Platinum Card®`(`cg-crd-2280`)는 상세 검증 기록이 있지만 단종 표시가 있어 이번 배치에서 제외했다. 현재 후보인 `American Express The Platinum Card®Edition2`는 별도 신규 발급 검증 대상으로 선정한다.
