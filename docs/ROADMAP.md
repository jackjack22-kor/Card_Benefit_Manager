# Roadmap

## v1
- 카드별 현황 중심 대시보드
- 카드 상세 혜택 사용관리
- 드래그/버튼 카드 순서 변경
- 사용처별 추천 탭
- JSON 백업/복원
- 신한 Always On 추가

## v1.1 (완료)
- CardFit 브랜딩(앱 이름·로고·파비콘·앱 아이콘)
- 설치형 PWA 지원(매니페스트, network-first 서비스워커, 오프라인)
- 카드현황·결제추천·카드상세·설정 UI 리디자인(브랜드 그라데이션, 아이콘 탭, 요약 칩)

## v1.2 후보
- 월별 사용 이력 보기
- 혜택 사용 메모
- 실적 제외 항목 체크리스트
- 카드별 숨김/고정 표시
- CSV/엑셀 명세서 업로드 후 실적 초안 산출

## v2 후보
- 로컬 암호화 백업
- 추천 엔진 점수 가중치 사용자 설정
- 카드사 공식 페이지 변경 추적 메모
